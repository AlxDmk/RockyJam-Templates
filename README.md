# RockyJam Templates

Custom page templates for WooCommerce product and category pages.

## Features
- Create, edit and delete custom templates via a dedicated admin UI
- Assign a template to individual products via a metabox in the product editor
- Global default template (auto-created on activation)
- CodeMirror-powered HTML editor with shortcode support

## Template tags
| Tag | Output |
|-----|--------|
| `[rjt_product_title]` | Product title |
| `[rjt_product_price]` | Price |
| `[rjt_product_gallery]` | WooCommerce gallery |
| `[rjt_product_description]` | Full description |
| `[rjt_add_to_cart]` | Add to cart button |

## Requirements
- WordPress 6.0+
- PHP 8.0+
- WooCommerce
